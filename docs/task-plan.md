## デザイン方針

既存のファーストビューを維持。白 #ffffff、インク #1a1d22、ブランド青 #37abd9、文字用青 #156f95、淡青 #e9f6fc、コミュニティの緑 #0a6e59。書体は既存Noto Sans JPを継続。

ヒーロー → 6枠の写真コラージュ → AI / コミュニティの2列 → 3つの取り組み → 会社概要 → お問い合わせ。
見出しと本文は左揃え、写真・図は横幅を大きく。カードの重複や過剰なラベルを避ける。動きは既存ヒーローとユーザー操作に絞る。

参考: [NEWPEACE](https://newpeace.jp/)の写真と短いプロジェクト説明。
画像: プロジェクト紹介は、アクセルのワークフロー説明図1枚と、Tokyo Global Hub・ちいきのかまどの公式活動写真2枚。説明図は設計イメージと明記。写真コラージュは6枠（同じ公式写真2枚＋差し替え用の空き枠4枚）。出典・差し替え方法は [photos.md](photos.md) に記録。

企業情報・連絡先は既存サイトから継承。成果数値や個別の担当実績は追加しない。既存ブログ・問い合わせAPI・法務ページを保持。
